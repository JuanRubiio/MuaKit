# Mua Ops v1.2.5

Release de cierre de la evolución de importación y de las mejoras del dominio de marketing.

## Alcance

- Patrón específico de MalagaPack: número de factura, productos, cantidades, envío, IVA y total.
- Patrón específico de Anthropic: proveedor automático, suscripción Claude Pro, inversión del sujeto pasivo e identificación separada de factura y recibo.
- Refuerzo de extracción OCR para AliExpress: paquetes, unidades, precios deformados y revisión obligatoria cuando el importe se reconstruye.
- Sugerencias de materiales para líneas de cadenas y preservación de líneas de producto con OCR incompleto.
- Mejoras de filtros, tooltips y diagnósticos de eficiencia en marketing.
- Evidencias OCR priorizadas por etiqueta para evitar marcar `Subtotal` como `Total` cuando los importes coinciden.

## Validación

- `npm test` — API, extracción, patrones, migraciones y regresiones.
- `npm run test:ui:smoke` — navegación y flujos principales de interfaz.
- Reprocesado real de la factura MalagaPack `T099926004399`.
- Reprocesado real de la factura Anthropic `9BF0758D-11252538`.
- Comprobación de que la bandeja queda sin procesos pendientes.
