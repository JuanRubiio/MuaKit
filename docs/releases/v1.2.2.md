# Mua Ops v1.2.2

Punto estable previo a la reconstruccion de Reposicion inteligente.

## Cambios principales

- Dashboard operativo y de rentabilidad con filtros temporales, colores configurables y navegacion contextual.
- Bandeja de importacion de gastos reforzada para PDF e imagen, con validacion supervisada y visor documental.
- Extraccion adaptada a facturas de Meta, AliExpress, Etsy, Shein y Shopify.
- Lineas de gasto con descuentos, IVA, paquetes e impresiones mejor alineados con la factura final.
- Sincronizacion Shopify con refresco transversal de los dominios afectados.
- Base funcional de reposicion inteligente y planes de compra disponible para su siguiente iteracion.

## Validacion

- `npm run test:ui:smoke`
- QA visual de Dashboard en escritorio y movil.
